Fountain of Dreams - HDSPCT

HDSPCT

The HDSPCT file seems to describe the different types of skills that are available in the game. There are 32 skills, 16 active, and 16 passive (although not all of them are used). I have no idea why it's called HDSPCT.

Offset Value Purpose
0x00-0x01 0x0700 Unknown, but probably little ending 7
0x02-0x03 0x1000 Number of active skills (0x10 or 16 in this case)
0x04-0x05 0x1000 Number of passive skills (0x10 or 16 in this case)
0x06 - 0x125 Variable Attribute data (Stength, IQ, Dexterity, etc.)
0x126-0x285 Variable Active skill names and their properties (16 records by 22 bytes)
0x286-0x3E5 Variable Passive skill names and their properties (16 records by 22 bytes)
0x3E6-0x49B Variable Condition and properties of the different conditions
